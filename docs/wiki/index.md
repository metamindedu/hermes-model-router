# 운영 지식 색인

- [[skill-policy-ownership]] — 플러그인 정책 단일 소유권, 독립 스킬 재생성 제거, 기존 파일 보존과 구 저장 계획 거부
- [[direct-main-default]] — 작은 수정의 Main 직접 처리, 실질적인 병렬 작업 기준과 위임 오버헤드, 단일 필수 검수 예외, 설치별 로컬 지침 보존
- [[task-slots]] — 목적별 내장 슬롯, 사용자지정 슬롯, 모델 선택과 읽기 전용 자문
- [[native-delegation]] — 목적·프로필 라우팅, 접근 권한, 예비 모델과 실행 근거
- [[total-runtime-limits]] — 슬롯별 기본 2시간, 일반·프로필 위임 기본 제한 없음, 분 입력과 초 단위 실행값
- [[profile-boundaries]] — 설정 적용 대상, 프로필별 라우팅과 별도 실행 권한
- [[fallback-boundaries]] — 대화·위임·슬롯 예비 모델의 적용 범위와 비용 동의
- [[execution-jobs]] — 네이티브 자식 실행 현황과 별도 게이트웨이 프로필 작업
- [[routed-session-visibility]] — 네이티브 작업의 표시와 이전 프로세스 작업 조회 종료
- [[fast-inheritance]] — 부모 세션의 Fast 선택과 만료, 지원되는 요청 경로
- [[model-selection]] — 모델 선택기와 추론 강도 보존
- [[settings-placement]] — 설정 페이지 위치와 배포·활성화 구분
- [[startup-compatibility]] — 이전 실행기의 시작 호환성 기록
