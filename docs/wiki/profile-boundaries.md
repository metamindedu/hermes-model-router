# 프로필 경계

Desktop 설정 화면은 앱 공용이지만 실행 패키지, 라우팅 사용 여부, 시간 제한은 프로필별이다. 패키지를 설치한 프로필에서 저장된 선택이 없으면 작업 분담은 기본으로 켜진다. 이미 저장된 OFF와 스킬 비활성화는 보존한다. 작업 분담을 꺼도 설정 화면을 사용할 수 있다. 설치나 설정 조회만으로 네이티브 위임 방식을 바꾸지는 않는다.

## 슬롯과 적용 대상

기본 Hermes 루트의 공유 저장소는 사용자지정 슬롯의 정의를 한 번만 저장한다. 같은 슬롯도 각 프로필에서 다른 모델과 실행 시간 제한을 쓸 수 있다. 모델과 시간을 지정하지 않은 슬롯은 Main 모델과 2시간 기본값을 쓴다. 적용 대상 목록은 저장할 프로필을 정하는 것이지 다른 프로필의 계정·도구·비용 사용 권한이 아니다. 모델이나 시간값을 선택했다고 사용 여부·예비 모델·비용 동의까지 복사하지 않는다.

## 프로필 실행 권한

네이티브 프로필 위임은 출발 프로필에 저장된 허용 목록을 확인한다. 대상 프로필의 모델·인증·정책을 사용하되 부모의 도구 범위를 넘을 수 없다. 별도 게이트웨이에서 실행하는 전체 프로필 작업은 별도의 운영자 승인이 필요하다. 둘 다 설치나 슬롯 저장으로 허용되지 않는다.
